# 阶段 4.2：Agent 内置工具自动装载

- 文档类型：交付记录
- 状态：代码、测试、Server 接入和文档已完成
- 日期：2026-09-08

## 本阶段目标

让 CraftAgent 的安全内置工具成为 Agent 默认能力，同时给应用提供无歧义的禁用、覆盖、追加和整体替换配置，
并从 Server 工具注册表中移除框架内置工具。

## 实际完成

- 新增稳定的 `BuiltinToolName` 和内置工具注册表。
- `defineAgentConfig()` 默认创建 `get_current_time` 与 `calculator`。
- 新增 `extend` 工具配置，支持 `disabledBuiltins`、`overrides` 和 `additional`。
- 新增互斥的 `replace` 模式，支持严格工具白名单。
- 三种工具输入都可直接接收 `defineTool()` 结果，由 Agent 配置边界先转换再去重和冻结。
- 配置阶段拒绝未知内置名称、禁用与覆盖冲突、覆盖名称不一致和最终集合重名。
- Server 注册表只保留 IP 定位与天气定义，不再调用额外组装函数，通过 `additional` 直接接入 Agent。
- 同步更新 Agent、Tool、Server 规范和两篇学习文档。

## 验证范围

- 未配置工具时自动装载全部内置工具。
- 禁用单个内置工具并追加应用工具。
- 显式覆盖单个内置工具。
- 完全替换内置工具集合。
- 歧义配置和重复名称在启动阶段失败。
- Server 最终仍向模型提供两个内置工具和两个应用工具。

## 后续范围

- 新增内置工具时继续执行安全、权限和通用性评审。
- 轨迹持久化与查询仍按阶段 5 推进。
