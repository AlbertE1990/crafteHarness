# 阶段 1：Tool Harness

- 文档类型：交付记录
- 状态：已完成
- 对应提交：`7bd5c2d`

## 本阶段目标

建立可独立测试、与模型 SDK 和 Web 框架无关的工具定义与执行内核。

## 实际完成

- 使用 Zod 4 作为输入、输出和 JSON Schema 投影的单一来源。
- `defineTool()` 把名称、描述、Schema、实现、重试和安全声明放在一起。
- `executeTool()` 实现输入校验、策略、单次审批、执行、幂等重试、协作式超时、输出校验与内容投影。
- 建立规范成功/失败结果和工具轨迹事件。
- 提供安全时间工具和结构化计算器，均不会自动注册。
- 明确第一方可信工具的安全边界，不把元数据校验描述为代码行为证明。

## 主要文件

- `src/common-agent/tools/*`
- `src/common-agent/builtins/*`
- `test/common-agent-tools.test.ts`

## 关键决定

- ADR-001：Zod 是工具协议单一来源。
- 工具默认不重试；只有声明幂等且错误可重试时才进入重试管线。
- 默认策略 fail closed；有外部能力的工具需要 Runtime 明确授权。
- 工具事件监听器失败不能改变业务结果。

## 验证

核心测试覆盖注册检查、输入输出边界、重试、权限拒绝、审批缺失、超时、观察器隔离和内置工具。

## 保留限制

- 同进程工具不是沙箱。
- 超时是协作式，忽略 AbortSignal 的同步代码不能被安全强杀。
- 工具事件尚未持久化，也尚未经过统一脱敏管线。
