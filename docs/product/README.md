# 产品与项目记录

本目录回答项目为什么这样设计、已经交付了什么以及下一步做什么。它不定义当前 API 的具体约束；
实现行为请以[开发规范](../standards/README.md)为准。

## 内容

- [分阶段开发路线图](./roadmap.md)
- [进行中的产品计划](./plans/README.md)
- [架构决策记录](./decisions/README.md)
- [阶段交付记录](./deliveries/README.md)
- [npm 首次发布清单](./npm-release-checklist.md)

## 状态语义

- Roadmap 可以包含未实现计划，必须明确标注阶段状态。
- ADR 保存设计原因；决定变化时使用 `Superseded` 和替代 ADR，不删除历史。
- Delivery 是某个时间点的交付快照，除事实纠错外不随当前实现反复改写。
